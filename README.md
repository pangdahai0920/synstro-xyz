# Synstro Cabinet Independent Site

B2B product showcase and inquiry site for Synstro network cabinets, PDUs, outdoor weatherproof cabinets, energy storage enclosures, and telecom boxes.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

Bind custom domains:

- `synstro.xyz`
- `www.synstro.xyz`
